# Default — neutral publication style

A functional, unbranded baseline. Use the exact values in tokens.ts; this prose
is guidance, not a replacement for tokens or rules. No application design file
participates in publication styling.

Use quiet paper surfaces, dark text, one restrained grayscale accent, and system
Arial typography. Keep one dominant message, clear reading order and substantial
negative space. The pack explicitly permits simple outline diagrams, abstract
geometry, paper-fold geometry, form diagrams and checklists used by existing
posts. It does not prescribe an industry, business identity, logo or new motif.

Portrait reads vertically with an editorial lead. Square uses a compact split
hierarchy when content allows. Story separates the lead, supporting information
and closing line with larger safe margins. Preserve message, ordering and visual
identity; do not scale or crop a finished canvas into another format.

Use plain, contained local images. Missing screenshots remain explicit asset
slots. No gradients, shadows, emoji decoration or rounded cards. A referenced
asset is not permission to introduce unrelated colors into authored HTML/SVG.

Canonical reference: content/2026/09/week-03/example-post (two slides, three
formats). examples/ may hold reviewed exports later; runtime never reads it.
